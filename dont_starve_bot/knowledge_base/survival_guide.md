# 饥荒高级生存指南

## 人物选择建议

### 新手推荐角色
- **Wilson（威尔森）**：全能平衡型，無特殊優勢和弱點，適合新手熟悉遊戲機制
- **Willow（威洛）**：天生怕火，但携带打火机，適合喜歡用火的玩家
- **Woodie（伍迪）**：可变身成海狸，推薦給想要不同體驗的玩家

### 进阶角色
- **Wendy（溫蒂）**：有妹妹分身阿比盖尔，可以两个人生存
- **Wolfgang（沃夫岡）**：力量型角色，饥饿消耗大，但战斗力强
- **WX-78（机器人）**：免疫精神打击，但怕水，可升级零件

## 基地规划

### 理想基地布局
1. **中央营火区**
   - 5-6个营火围成圈
   - 中间放置冰箱和炉灶
   - 用围墙隔离（防止怪物入侵）

2. **农业区**
   - 远离营火（防止火灾蔓延）
   - 种植常见蔬菜
   - 配置粪便分解器提高产量

3. **科技区**
   - 科学机器、炼金引擎等
   - 便于升级研发技术

4. **储存区**
   - 多个冰箱
   - 存储不同类别的物品
   - 防止物品散落

### 防御系统
- **围墙**：阻挡普通怪物
- **尖刺陷阱**：对付地下蜘蛛和小怪物
- **战术陷阱**：圆形陷阱阵列对付强敌
- **营火/火焰**：对付某些怪物（如黑手党、暗影生物）

## 中期发展路线

### Week 2-3：扩张与研发
1. 升级工具（铁镐、铁斧）
2. 建造冰箱和炉灶
3. 制作魔法装备（防护盔甲、鼠王冠冕等）
4. 研究科技树：工程、农业、炼金

### Week 4-8：巩固基础
1. 建造永久营地并加固防御
2. 建立稳定的食物来源
3. 制作更好的武器（暗影剑、战斧等）
4. 探索地下洞穴（获取稀有资源）

### Week 8+：长期生存
1. 建造多个卫星基地
2. 挑战Boss（树精卫士、月亮怪物等）
3. 优化生产线（自动化采集）
4. 积累财富（收集珍贵物品）

## 常见Boss及应对策略

### 树精卫士（Treeguard）
- **触发条件**：砍太多树，会自动出现
- **弱点**：水、火（但要小心）
- **掉落**：树精卫士之眼（强大魔法装备）
- **策略**：
  * 在水边战斗（利用水来减速它）
  * 制作陷阱进行诱导
  * 准备高伤害武器（暗影剑推荐）

### 蜘蛛女王（Spider Queen）
- **位置**：地下洞穴深处的蜘蛛巢
- **弱点**：火、高伤害武器
- **掉落**：蜘蛛卵、各种蜘蛛资源
- **策略**：
  * 准备足够的补给品
  * 使用火焰攻击
  * 引离巢穴进行单对单战斗

### 黑手党（Deerclops）- 冬季Boss
- **出现条件**：冬季时在地表活动
- **掉落**：鹿角（制作冬帽材料）
- **策略**：
  * 在基地附近设置陷阱
  * 提前准备好食物和武器
  * 利用火堆进行防御

## DST（联机模式）特殊要点

### 多人合作优势
- 更多手采集资源
- 分工提高效率
- 联合对付Boss

### 注意事项
- 避免物资争夺冲突
- 建立清晰的分工规则
- 防范玩家破坏（建立权限系统）
- 定期清理死亡物品堆积
