# 饥荒基础知识

## 核心机制

### 1. 理智值 (Sanity)
- 定义：角色的心理健康状态指标
- 恢复方式：
  * 睡眠（效果最好）
  * 进食合理食物
  * 查看科学装置
  * 与其他角色互动（DST）
- 下降原因：
  * 黑暗中活动（每秒 -0.6）
  * 看到敌对生物
  * 穿着破损的装备
  * 在沼泽、洞穴地形
- 临界影响：
  * 75%：开始偶尔自动攻击
  * 50%：频繁奇怪行为
  * 25%以下：有概率产生影子生物（影子怪物）

### 2. 饥饿值 (Hunger)
- 定义：角色的能量等级
- 消耗速度：
  * 正常活动：每分钟 -0.6
  * 奔跑：每秒 -1.5
  * 游泳：每秒 -1.5
  * 挖掘：每秒 -0.3
- 低于0的后果：
  * 0-100：开始掉血（每秒 -0.25）
  * 血量过低：会倒地死亡

### 3. 血量 (Health)
- 初始血量：150（大多数角色）
- 恢复方式：
  * 吃食物（最直接）
  * 火焰附近取暖（缓慢回复）
  * 医疗物品（急救包、蚂蚁药水等）
- 死亡触发：血量 ≤ 0

## 四季变化

### 春季 (Spring)
- 温度：适宜
- 主要威胁：蜘蛛和青蛙大量繁殖
- 生存策略：
  * 大量采集蜘蛛丝和毒囊
  * 制作网陷阱对付青蛙
  * 准备夏季所需的冰块和冷却装备

### 夏季 (Summer)
- 温度：极高（需要防护）
- 主要威胁：过热死亡、火灾、蚊子
- 生存策略：
  * 穿冰装或冬帽
  * 制作冰箱保存食物
  * 避免在烈日下挖矿（容易着火）
  * 制作冷却装备（冰棒、花洒帽等）

### 秋季 (Autumn)
- 温度：开始下降，为冬季做准备
- 主要威胁：树木脱叶，食物变少
- 生存策略：
  * 大量储备食物（干燥食物、腊肉）
  * 采集草和树枝为冬季造火
  * 建立永久基地和火堆

### 冬季 (Winter)
- 温度：极低（需要持续保暖）
- 主要威胁：冻死、资源稀缺、白鹿（特殊生物）
- 生存策略：
  * 建造多个火堆
  * 制作冬帽和保温衣
  * 吃高饱食度食物维持体温
  * 采集冬季才有的资源（冬草、枯根等）

## 初期存活要点

1. **第1天：建立基地**
   - 砍树、采草、挖石头
   - 制作营火（3根木头+3块石头）
   - 建立简易基地

2. **前5天：资源收集**
   - 采集足够的木头和石头
   - 制作镐子、斧头等工具
   - 建立冰箱（推荐）

3. **第1周：度过第一个夜晚**
   - 准备好营火和食物
   - 避免探索太远（容易迷路或遇怪）
   - 建立简易农场（optional）

4. **后期：季节适应**
   - 为即将到来的季节做准备
   - 扩建基地，建造更多设施
   - 研究科技树，升级武器和工具
