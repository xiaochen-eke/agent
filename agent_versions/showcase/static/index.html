三版本 Agent 对比▮

      
同一个「饥荒物品顾问」任务，三种编排方式：原生手写 / LangGraph 建图 / Dify 可视化

      

        
        
        
      

      
      
    


    

      

        
原生版

        
Native

        
手写 Python 控制流（if/elif），requests 直调 LLM，工具是直接 import lookup()。零框架、最可控。

        
      


      

        
LangGraph 版

        
LangGraph

        
StateGraph 把「意图 → 工具 → 回答」显式建模成节点 + 条件边，状态在 TypedDict 里流转。

        
      


      

        
Dify 版 · 游戏大脑

        
Dify 游戏大脑

        
不是物品问答，而是接入你真实游戏的生存大脑（Dify 链 app 3ff0efd8）：规划 → 建议 → GLM 决策动作 → 回灌 state_api。

        

          
          在 Dify 打开 ↗
        

      

    


    

      三版对同一输入应输出语义等价的回答 —— 证明「同一功能，三种编排」。
